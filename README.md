# HSE_LLM_PRE_TRAIN
Домашняя работа по курсу "Большие языковые и мультимодальные модели" магистратуры HSE & Авито. Цель работы: провести мини-претрейн LLM на википедии, поиграться с гипер параметрами, оформить отчет.

## Фиксированные условия

| Параметр | Значение |
| --- | --- |
| Модель | Qwen3 около 1B параметров |
| Инициализация | Случайные веса, обучение с нуля в каждом эксперименте |
| Датасет | `load_dataset("wikimedia/wikipedia", "20231101.ru", split="train")` |
| Evaluation | Первые 5000 статей в исходном порядке |
| Train | Все остальные статьи; перемешивание только после разделения |
| Токенизатор | `ai-forever/rugpt3small_based_on_gpt2` |
| Длина примера | 512 токенов, обрезка и padding каждой статьи |
| Обучение | 15 минут |
| GPU | Одна NVIDIA A100 80 GB |

## Эксперименты

Проведено девять запусков с нуля, по 15 минут каждый, с одинаковым seed 42. Базовая конфигурация: microbatch 8, gradient accumulation 4, LR `5e-5`, `constant_with_warmup`, AdamW fused, BF16 и TF32, без `torch_compile`. Во всех запусках effective batch равен 32, warmup — 30 шагов, weight decay — 0.01.

| Запуск | Опорный запуск | Изменение | Финальный eval_loss ↓ |
| --- | --- | --- | --- |
| `baseline` | — | Базовая конфигурация | 6.216 |
| `batch16` | `baseline` | Microbatch 16, accumulation 2 | 6.177 |
| `batch32` | `baseline` | Microbatch 32, accumulation 1 | 6.154 |
| `lr1e4` | `batch16` | LR `1e-4` | 5.158 |
| `lr3e4` | `batch16` | LR `3e-4` | 4.659 |
| `cosine` | `lr3e4` | Cosine scheduler, горизонт 1206 шагов | 4.829 |
| `compiled` | `lr3e4` | `torch_compile=True` | **4.268** |
| `adamw` | `lr3e4` | `optim=adamw_torch` | 4.669 |
| `no_tf32` | `lr3e4` | `tf32=False` | 4.653 |

Сначала проверялось, ускорит ли обучение увеличение microbatch при сохранении effective batch. Более крупные microbatch позволили обработать больше данных за отведённое время и немного снизили loss. Для следующих экспериментов использовалась комбинация 16 × 2: она близка по скорости к 32 × 1, но требует меньше памяти.

Затем увеличивался learning rate, чтобы ускорить обучение с нуля. Переход от `5e-5` к `1e-4` и `3e-4` заметно улучшил результат без признаков расходимости. Cosine scheduler проверялся с уменьшением LR до нуля за число шагов, достигнутое в `lr3e4`. Он оказался хуже постоянного LR после warmup: вероятно, на таком коротком обучении снижение шага было преждевременным.

Наибольший прирост скорости дал `torch_compile`: с учётом начальной компиляции модель обработала примерно в 1.5 раза больше токенов, чем в `lr3e4`, и получила лучший eval_loss. Обычный AdamW оказался немного медленнее fused-версии при близком качестве. Отключение TF32 почти не повлияло на результат; BF16 использовался во всех запусках, его отдельного сравнения с FP32 не проводилось.

Train loss сначала быстро падает, затем снижается медленнее и колеблется между батчами. При увеличении LR снижение становится заметно быстрее. ## Примеры генераций

Ниже — фрагменты продолжений лучшего запуска `compiled`. До и после обучения использовались одинаковые промпты, seed 42 и максимум 128 новых токенов.

Промпт: **«В начале XX века»**. До обучения, greedy:

> учебно ищут практикукновТерцет Леонид продунизма допустить командиры контракт годится радикально…

После обучения, greedy:

> в деревне была построена каменная церковь, а в начале XX века была освящена деревянная церковь.

Появились узнаваемые фразы и стиль энциклопедической статьи, но дальше модель повторяет «с 1926 года — в составе Белецкого района». Соответствие промпту тоже остаётся слабым: на **«Москва —»** она продолжает «советский хозяйственный, государственный и политический деятель».

Sampling с temperature 0.8, top-p 0.95 и top-k 0 делает текст разнообразнее, но не устраняет смысловые ошибки. Например, на **«Искусственный интеллект —»** модель отвечает:

> это завершение народа, которое может быть получено для обозначения создания.

## Выводы

Лучший из проверенных вариантов — microbatch 16, accumulation 2, LR `3e-4`, `constant_with_warmup`, AdamW fused и `torch_compile`, с BF16 и TF32. Финальный **eval_loss — 4.268, perplexity — 71.39**. Главный вклад внесли увеличение learning rate и ускорение обучения компиляцией.

За 15 минут модель начала воспроизводить локальную структуру русского языка и стиль Википедии. Связность длинного текста, соответствие теме и фактическая точность остаются слабыми. Каждый вариант проверялся с одним seed на одной отложенной выборке, поэтому небольшие различия между близкими результатами не стоит считать устойчивыми.
